# 发布验证

验证日期：2026-10-24。环境：Windows、TouchDesigner 2023.11600。

- 对最后保存的 Lantern 刀光／闪避版制作独立副本，重定位模型及图集路径后，保存至本仓库根目录。
- 关闭打包用 TD 进程，从仓库中的 `Lantern.toe` 重新启动 TD。
- 原生 TD 遍历文件／文件夹参数：没有缺失的运行资源，没有指向包外的自定义资源。四处未启用的标准人脸 OBJ 读取器使用锁定的内嵌几何，不需要外部 OBJ。
- 冷启动时节点错误和脚本错误均为空；游戏输出为 1280×720，两张图集均为 1448×1086，原始武器网格为 97 个点，待机武器隐藏。
- 相关 Python 算法回归：`python -m pytest -q`，85 项通过。包含游戏状态、跳跃／闪避、Boss 碰撞和击退、武器方向、特效时间、手腕／手指与骨架约束。
- 独立资源校验：`python tools/verify_bundle.py`，检查工程、两个模型、两个图集的字节数和 SHA-256。

验证时未连接 DualSense，存在“Selected joystick not connected”警告。MediaPipe 浏览器启动时可能留下 `ERR_ABORTED` 警告；使用时需要在本机选择摄像头并允许访问。本次打包验证没有真人动作和实际手柄操作验收，也不将缓存数据视作实时跟踪成功。

`docs/gameplay.png` 为本次从仓库工程生成的游戏 Render TOP 画面，不包含摄像头画面。临时日志、导入缓存、旧工程、开发桥接脚本和个人调试图像不进入仓库。
