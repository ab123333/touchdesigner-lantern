# 实现结构

`/project1/knight_game/game_state` 是 Script CHOP：以 120 Hz 固定时间步执行平台移动、动作状态、战斗窗口、碰撞与生命值，输出 CHOP 通道供场景节点引用。`art_state` 将游戏状态转为转身、步态、披风和武器动画。使用正交相机渲染 3D 模型得到 2D 侧视效果。

摄像头经内嵌 MediaPipe 浏览器组件生成身体及手部关键点。`/project1/script1_callbacks` 求人体参考坐标系与骨骼局部旋转，使用位置滤波、四元数平滑和关节约束。`hand_callbacks` 求掌面与手指旋转。输出同时驱动原 Y_Bot 和游戏 Boss。

Boss 碰撞由真实骨骼世界坐标建立上臂、前臂、手掌、大腿、小腿和脚部胶囊。对运动做时间采样，用局部运动速度计算有界击退，并拒绝跟踪跳变产生的异常惯性。失去跟踪时不继续产生动态挥击。

GLSL MAT 实现分档明暗及轮廓。攻击和闪避通过 GPU 采样 4×3 图集，去除暗色背景、插值帧并做加法合成。原武器网格随攻击相位旋转，攻击结束隐藏。

发布版统一从工程根目录解析 `assets`。MediaPipe VFS 留在工程内部，`asset_installer` 已禁用且无外部脚本入口。运行日志写入 `.runtime`。所有运行所需自定义代码已内嵌，源码导出用于审阅和后续开发。
